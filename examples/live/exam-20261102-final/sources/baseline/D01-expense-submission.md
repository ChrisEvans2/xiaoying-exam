# 差旅报销基本规定

本文为虚构公司的合成制度，仅供项目开发与评估使用。

1. 员工应在出差结束次日起 30 个自然日内提交差旅报销申请。自然日包含周末和法定节假日。
2. 同一次出差应合并提交一份申请，写明出差事由、起止日期、目的地和各项费用。
3. 交通费与住宿费须提供有效发票或相应合法报销凭证，并附出差审批记录。电子发票与纸质发票具有相同的内部报销效力。
4. 餐费补贴按《境内差旅餐费补贴规定》（D05）申请，无须提供餐饮发票。
5. 与公务无关的个人消费不予报销。同一笔费用不得重复申请。
