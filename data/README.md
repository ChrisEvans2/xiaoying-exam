# 合成知识库说明

本目录包含虚构的“青屿示例科技有限公司”的 8 份报销与差旅短制度，格式分布为 4 份 Markdown、1 份 Word、1 份 PDF、1 份 HTML 和 1 份 TXT。公司名称、制度条款、金额和日期均为项目合成内容，不代表真实公司的规定，不含真实员工或业务资料。

## 检索边界与格式

- 知识库正文仅为 `data/policies/` 下的 `.md`、`.docx`、`.pdf`、`.html` 和 `.txt` 文件。本说明及 `docs/` 中的设计、评估材料不作为业务检索资料，避免将场景说明当成制度依据。忽略 `.DS_Store` 等非业务文件。
- 每个文档 ID 只对应一份文件，已转换文档不再保留同目录下的 Markdown 副本，避免重复入库。
- 所有格式均保留文档 ID、标题、公司、版本日期、适用范围及合成标记，且转换不改变正文条款。
- Markdown 使用 YAML front matter，字段为 `document_id`、`title`、`company`、`version_date`、`scope`、`synthetic`。
- Word 和 PDF 将标题及元数据作为可读文字写在文档开头；PDF 含可提取的中文文本层与嵌入字体，不是扫描图片。
- HTML 使用 UTF-8 编码，提供同名 `<meta>` 字段和可见元数据，条款位于 `<article>` 内的有序列表，无外部资源依赖。
- TXT 使用 UTF-8 编码，先列标题和“文档 ID、版本日期、公司、适用范围、合成材料”字段，再列编号条款，无 Markdown 标记。
- `version_date` 是文档版本日期，不单独代表生效优先级或替代关系。
- 资料范围为中国大陆境内公务差旅及劳动合同员工（含试用期）。未提供实习生、外包人员、境外及港澳台差旅规则。

## 场景设计说明（非业务依据）

- **明确答案**：D03—D08 提供可直接引用的规则，也提供可组合读取的跨文档引用。
- **有意保留的冲突**：D01 规定出差结束次日起 30 个自然日内提交，D02 规定同一起点的 15 个自然日；适用范围相同。两份原文均未给出优先级或替代关系，不能仅凭 D02 日期较新就解决冲突。
- **上下文条件**：D04、D05 中试用期员工与已转正员工标准相同，D06 中预借款资格不同，可支持“那试用期呢”等追问。
- **信息缺口**：没有境外差旅、签证费用、实习生差旅待遇及实际付款到账时限的规定。缺少规定不等于制度禁止，应说明资料不足。
- **问题改写**：自然语言规则包含“住宿费用”“餐费补贴”“预借款”等业务表达，可用于检查“住酒店能报多少”“出差能先借钱吗”等不同问法的检索效果。
- **工具失败**：应在后续工具实现中注入可重复的故障；不在制度正文中伪造工具错误。

以上仅说明数据的设计用途，不代表 Agent 已通过验收。目前尚未生成真实问答输出、模型 Trace 或效果评估结果。
